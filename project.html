Project: Daily Score

Project Overview

Personal Productivity & Wellness Tracking Website

Daily Score is a personal productivity and wellness tracking website designed to help users evaluate how well they used their day. The goal of the project was to create a simple way to track progress across multiple areas of daily life rather than focusing on only one habit.

Purpose

The website allows users to reflect on areas such as health, productivity, personal growth, and social balance and then calculate an overall score for their day.

Core Tracking Categories

  • Health & Fitness: Exercise or lifting, cardio, protein and nutrition goals
  • Productivity: Schoolwork, productive use of free time
  • Life & Social: Time with friends or family, new experiences
  • Personal Growth: Skill progression and continuous learning

Features

  • Interactive Daily Checklist: Easy-to-use checklist items to log daily activities across multiple categories.
  • Organized Life Categories: Groups habits and goals into structured areas of a user's day.
  • "Calculate My Day" Tool: On-page evaluation triggered directly by user completion.
  • JavaScript-Based Scoring: Client-side scoring algorithm that tallies selections across categories.
  • Final Daily Score & Grade: Displays an immediate score and evaluation grade based on selections.

Technologies Used

  • HTML: Webpage markup and semantic content structure.
  • CSS & ZURB Foundation: Layout, styling, and responsive UI framework.
  • JavaScript & jQuery: Interactive DOM manipulation, checklist tracking, and score calculation logic.
  • Git & GitHub: Version control and repository hosting.
  • GitHub Pages: Live website deployment and hosting.

What I Learned

Building Daily Score gave me experience turning an idea into a working interactive website. I learned how HTML structures a webpage, CSS controls the appearance, and JavaScript can respond to user input and calculate results.
